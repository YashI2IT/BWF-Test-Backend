# BWF-data

Data workspace for BWF.

## Structure

- `excel/incoming` - raw Excel sheets received from teams
- `excel/processed` - cleaned and validated files
- `excel/archive` - old versions kept for traceability
- `excel/templates` - approved templates
- `excel/exports` - generated reporting outputs

## Legacy files

Existing top-level `.xlsx` files are kept as legacy references and can be moved into the `excel/` flow during maintenance.
